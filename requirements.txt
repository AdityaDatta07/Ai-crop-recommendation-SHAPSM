# Runtime dependencies for apps/api.
#
# Pinned to the versions this was developed and tested against. A deploy that
# silently picks up a newer FastAPI or Pydantic is a deploy that can fail in a
# way the local test suite never sees — and the first time you would find out
# is on demo day.
#
# Install:  pip install -r requirements.txt
# Run:      uvicorn apps.api.main:app --host 0.0.0.0 --port $PORT
#
# NOTE ON THE RUN COMMAND: it must be executed from the REPOSITORY ROOT, not
# from apps/api. The API imports `services.geo`, `services.ml` and reads
# `data/reference/*.yaml`, all of which live at the root. Setting a host's
# "root directory" to apps/api will produce ModuleNotFoundError: services.

#   - No Supabase -> falls back to SQLite on local disk. Fine for a demo,

#     every shareable /r/<id> link dies on restart.
#   - No Earth Engine -> USE_MOCK_GEO=true serves recorded conditions and the
